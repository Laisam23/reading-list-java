# Reading List Java

A small Java project built to practise object-oriented programming fundamentals.

## Goal

Build a simple reading-list application while improving my understanding of Java through code I can explain, modify and maintain independently.

## Planned features

- Add a book
- View all books
- Search for a book by title
- Remove a book
- Show the number of books in the reading list
- Handle invalid input safely

## Concepts I want to practise

- Classes and objects
- Constructors
- Fields and methods
- `ArrayList`
- Conditionals
- Loops
- Strings
- Index handling and validation

## Development rule

The application code in this repository is written as a learning project. I only commit code that I understand and can explain.
